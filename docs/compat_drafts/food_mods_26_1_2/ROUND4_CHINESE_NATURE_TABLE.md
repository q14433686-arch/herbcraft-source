## 三、按模组分组说明

### 1. 农夫乐事 Refabricated

- **卷心菜 / 卷心菜叶**：平，甘淡，草叶、补益。定位为温和叶菜，给玩家一点“可辨性味”，但不当强药。
- **卷心菜种子 / 番茄种子**：平，淡，古怪。与原版种子风格对齐，避免“种子也补益”的过度解释。
- **洋葱**：微温，辛甘，行散、土气。它是本组里最像“辛香药食”的东西。
- **南瓜片**：平，甘淡，古怪。接近原版南瓜的轻性味，不加补益。
- **稻米**：平，甘淡，补益。主食谷物，轻补而不神化。
- **番茄**：微寒，甘酸，补益、清解。酸甘生津，略取清解。

### 2. More Delight（更多乐事）

本轮没有 More Delight 性味条目。它当前保留的多数是熟食、吐司、三明治、汤、汉堡与配餐，应归入食材录和营养表，不抢百草经的药理位置。

### 3. Reg's More Foods（Reg 的更多食物）

- **咖啡豆**：微温，苦辛，行散、土气。它是新增的植物性刺激物候选，但 RMF 的物品身份必须客户端验证。
- **爆米花种子 / 番茄种子**：平，淡，古怪。按种子类保守处理。
- **南瓜片 / 米粒 / 番茄**：分别按农夫乐事/原版类似物处理；RMF 身份仍需客户端测试。
- **香蕉、黑莓、蓝莓、树莓、草莓**：Round 3 已取消百草性味，只保留食材录和营养。普通水果不应自动变成药性条目。

## 四、性质词典

### 性

- `cold`：寒
- `cool`：微寒
- `neutral`：平
- `warm`：微温
- `hot`：辛热

### 味 / 入口味

- `sweet`：甘
- `bitter`：苦
- `pungent`：辛
- `sour`：酸
- `astringent`：涩
- `salty`：咸
- `bland`：淡

### 特质

- `clearing`：清解。似有清解之性。
- `toxic`：毒性。毒性隐伏，慎入口。
- `nourishing`：补益。气味温和，似可补益。
- `stirring`：行散。药性行散，不宜轻忽。
- `sedating`：镇缓。气息沉静，似可镇缓。
- `aquatic`：水润。水润之性，清凉入喉。
- `fiery`：火烈。火烈上行，入口生热。
- `withered`：枯败。枯败之气缠绕其上。
- `nether`：下界。下界异性，辛烈难驯。
- `floral`：芳香。芳香浮动，药意轻扬。
- `resinous`：脂涩。脂涩黏滞，药性久留。
- `fungal`：菌性。菌性幽微，变化难测。
- `lunar`：阴幽。阴幽微凉，夜气未散。
- `solar`：阳明。阳明温润，似含日气。
- `leafy`：草叶。草叶清涩，入口见性。
- `icy`：寒凝。寒意凝结，慎防伤胃。
- `slimy`：滑腻。滑腻成性，入口难忘。
- `honeyed`：甘润。甘润黏香，易生餍足。
- `earthy`：土气。土气未脱，质朴沉稳。
- `addictive`：牵缠。镇缓之余，亦有牵缠。
- `curio`：古怪。性味古怪，非一口可尽知。
