# MC 26.3 新增物品：适配方向备选（2026-10-14）

目的：列出 26.3 新增的物品，判断每个物品与 Herbcraft 的关系，并给出几个可选的适配方向，由维护者选择。
本文档不改任何代码或数据。选定方向后再实施。

## 1. 26.3 新增物品清单（已核实）

来源（快照与 Java 版开发版说明）：
- 26.3 Snapshot 1：Dappled Forest 群系、Poplar 树（红/橙/黄三色叶）、Shelf Mushroom、Red Shrub、Poplar 木材套、Wool 台阶与半砖 [1](https://www.minecraft.net/en-us/article/minecraft-26-3-snapshot-1)
- Java 开发版说明（Snapshot 1）：Poplar 木材套（门、告示牌、悬挂告示牌、船、按钮、压力板、栅栏、活板门、货架、台阶、半砖）、新的 `#poplar_logs`、`#wool_stairs`、`#wool_slabs`、`#ores`、`#skulls` 等标签 [3](https://minecraft.wiki/w/Java_Edition_26.3/Development_versions)
- 26.3 Snapshot 3：Cushion（坐垫，16 色，可坐）、Straw Bed（稻草床，一次性，3 个干草块合成 4 个，不能在下界/末地使用）[4](https://www.reddit.com/r/Minecraft/comments/1upvzap/minecraft_263_snapshot_3/)
- Shelf Mushroom 细节：小/大两种，骨粉可由小长大；大蘑菇掉 2 个；可用于煮蘑菇煲；流浪商人可交易；踩上去有弹性 [2](https://www.bisecthosting.com/blog/minecraft-26-3-release-date-patch-notes-more)
- Poplar 叶会掉落 Poplar 树苗，树苗可由流浪商人交易，长出三种颜色之一 [1](https://www.minecraft.net/en-us/article/minecraft-26-3-snapshot-1)

## 2. Herbcraft 现有相关结构（已核实）

- `core/.../data/herbcraft/herbs.json`：96 种草药，**包括**所有树叶（如 `minecraft:cherry_leaves`）、树苗（如 `minecraft:cherry_sapling`）、`minecraft:brown_mushroom`、`minecraft:fern`、`minecraft:dandelion` 等。新草药要加进这张表。
- `alchemy/.../data/herbcraft_alchemy/essences.json`：40 个精华（essence）。已有 `essence_cherry_leaves`、`essence_cherry_sapling`、`essence_brown_mushroom` 等。精华由 `scripts/generate_essence_resources.py` 生成骨架。
- 酿造配方：520 条（约每个精华 13 条）。
- 营养档案：`core/.../data/herbcraft/nutrition_profiles.json`（约 162 条）。
- **自动影响点（必须决定）**：`cuisine/.../dishes.json` 的 `honey_leaf_soup` 和 `recipe/raw_honey_leaf_soup.json` 都使用 `#minecraft:leaves`。如果 Poplar 叶被原版加进 `#leaves`（需在 26.3 数据中确认），它们会自动成为这两道菜的合法食材，不需要任何改动。
- 仓库里没有用到原版 `#planks`、`#wool`、`#stairs`、`#slabs`、`#mushrooms`、`#saplings` 的配方，所以木材、羊毛和蘑菇类新成员不会因为标签而自动进入 Herbcraft 配方。

## 3. 逐物品方向

### 3.1 Shelf Mushroom（小 / 大）— 与 Herbcraft 高相关

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 完整草药** | 加入 `herbs.json`（小、大各一条，或只加大蘑菇）；生成 `essence_shelf_mushroom` 并配酿造配方；补营养档案与 Codex 条目 | 大（约 25–30 个文件） | 与 `brown_mushroom` 一致，是最完整的接入 |
| B 仅食物 | 加入 `herbs.json` 与营养档案，不做精华和酿造 | 小 | 进食有效，Codex 只显示食物属性 |
| C 仅烹饪食材 | 不做草药，把它作为 cuisine 里某些 `raw_*_stew`（约 8 个 stew 菜谱，如 `raw_seafarer_stew`、`raw_resin_guard_stew`）的食材，或新增一道蘑菇汤 | 中 | 目前 cuisine 数据里没有任何蘑菇引用，需要新增菜谱或改现有菜谱的食材列表才有意义 |
| D 不适配 | 不改数据，只保证不崩溃 | 无 | 玩家可以吃，但没有 Herbcraft 的任何效果 |

**推荐：A**。理由：`brown_mushroom` 已经是完整草药，Shelf Mushroom 同属蘑菇，接入成本可控，且能复用 `generate_essence_resources.py`。

### 3.2 Red / Orange / Yellow Poplar Leaves（三色叶）— 与 Herbcraft 高相关

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 三色各一个精华** | 三种叶子各加入 `herbs.json`，各生成一个 `essence_poplar_*_leaves`，各配酿造配方 | 大（3 套，约 75–90 个文件） | 与现有 `essence_cherry_leaves` 等树叶模式一致，效果可分别设计 |
| B 合并为一个精华 | 三色叶合并成 `essence_poplar_leaves`，只在 Codex 显示颜色 | 中 | 最省事，但三色失去区分度 |
| C 仅食物草药 | 加入 `herbs.json` 与营养档案，不做精华 | 小 | 与方向 B 的小版本一致 |
| D 不适配 | 不加草药数据 | 无 | 但 `#minecraft:leaves` 的自动影响仍然发生，需要单独决定（见下） |

**关于自动影响（无论选哪个方向都要决定）**：Poplar 叶如果进入 `#minecraft:leaves`，它会自动成为 `honey_leaf_soup` 和 `raw_honey_leaf_soup` 的合法食材。建议接受（这是树叶，符合原意），但需要在 26.3 数据里确认 `#minecraft:leaves` 是否包含 Poplar 叶。

**推荐：A**。理由：树叶在 Herbcraft 中是一整类草药，三色正好对应三种效果。若工作量需要压缩，选 B。

### 3.3 Poplar Sapling（Poplar 树苗）— 与 Herbcraft 中相关

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 草药 + 精华** | 加入 `herbs.json`；生成 `essence_poplar_sapling`，与 `essence_cherry_sapling` 对齐 | 中 | 树苗在 `herbs.json` 中已有先例 |
| B 仅草药 | 只加入 `herbs.json` 与营养档案 | 小 | 无酿造 |
| C 不适配 | 不改数据 | 无 | 只有流浪商人交易和种植生效，与 Herbcraft 无关 |

**推荐：A**，与 `cherry_sapling` 完全对齐。若想减少工作量，选 C。

### 3.4 Red Shrub（红灌木）— 与 Herbcraft 中相关（低优先）

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| A 草药 + 精华 | 加入 `herbs.json`，生成精华，与 `fern` / `short_grass` 类似 | 中 | 它是方块，需要确认 `herbs.json` 的 `item` 字段对方块物品是否有效（`fern` 也是方块，所以有先例） |
| **B 仅装饰 / 堆肥** | 不做草药；只依赖原版行为（堆肥、骨粉） | 无 | 与 Herbcraft 的草药系统没有直接关系 |
| C 不适配 | 不改数据 | 无 | 同 B |

**推荐：B**。它是装饰植物，不是草药，只有在你想让 Herbcraft 的"草药"覆盖所有植物时才需要做 A。

### 3.5 Cushion（坐垫，16 色）— 与 Herbcraft 无关

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 不适配** | 不做任何改动 | 无 | 纯装饰/家具，Herbcraft 没有坐、椅、家具系统 |
| B 加入创造栏 | 把坐垫加入 Herbcraft 的创造物品栏 | 小 | 只有在 Herbcraft 的创造栏是"全部物品"时才有意义，目前不是 |
| C 新机制 | 例如坐在坐垫上时享受草药相关的小幅恢复 | 大（需要设计与测试） | 新功能，不属于适配 |

**推荐：A**。

### 3.6 Straw Bed（稻草床）— 与 Herbcraft 无直接关系

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 不适配** | 不做任何改动 | 无 | 原版床行为由原版处理，Herbcraft 的死亡与复活逻辑不依赖床 |
| B 草药主题机制 | 例如睡在稻草床上获得"安神"类效果 | 大（新功能） | 需要设计，不属于适配 |

**推荐：A**。

### 3.7 Wool Stairs / Wool Slabs（羊毛台阶与半砖）— 与 Herbcraft 无关

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 不适配** | 不做任何改动 | 无 | Herbcraft 没有使用羊毛的配方或标签 |
| B 加入创造栏 | 同 3.5 方向 B | 小 | 同上，目前不适用 |

**推荐：A**。

### 3.8 Poplar 木材套（原木、木板、门、告示牌、船等）— 与 Herbcraft 无关

| 方向 | 做什么 | 代价 | 说明 |
|---|---|---|---|
| **A 不适配** | 不做任何改动 | 无 | Herbcraft 的草药只用树叶与树苗，不用木材；木材的标签不影响现有配方 |
| B 作为草药材料 | 把木材与草药关联（例如木材作为烟熏或燃料） | 大（新功能） | 需要设计 |

**推荐：A**。

## 4. 其他 26.3 变更（不是新物品，但会影响 Herbcraft）

- **Mushroom Stew / Suspicious Stew 可以用任意 2 个蘑菇合成**（26.3 原版改动，见 [2](https://www.bisecthosting.com/blog/minecraft-26-3-release-date-patch-notes-more)）。Herbcraft 的 `spicy_mushroom_stew` 和 `mushroom_rice` 是自定义菜谱，不受此影响；需要确认 Herbcraft 是否覆盖了原版的蘑菇煲合成（目前未检查）。
- 地图（Explorer Map）新增图标与类型：与 Herbcraft 无关，不需要适配。

## 5. 汇总与推荐

| 物品 | 与 Herbcraft 关系 | 推荐方向 |
|---|---|---|
| Shelf Mushroom | 高 | A 完整草药 |
| Poplar 三色叶 | 高 | A 三色各一个精华（或 B 合并） |
| Poplar 树苗 | 中 | A 草药 + 精华 |
| Red Shrub | 低 | B 仅装饰/堆肥 |
| Cushion | 无 | A 不适配 |
| Straw Bed | 无 | A 不适配 |
| Wool 台阶与半砖 | 无 | A 不适配 |
| Poplar 木材套 | 无 | A 不适配 |

**需要维护者决定的开放问题**：
1. Poplar 叶是否接受为 `honey_leaf_soup` 的食材（自动发生，除非把叶子排除出 `#leaves`）。
2. Shelf Mushroom 是否分小、大两个草药，还是只做大蘑菇。
3. 是否把 Red Shrub 纳入草药（默认不纳入）。

## 6. 下一步（选定方向后）

- 按选定方向修改 `herbs.json`、`essences.json`、营养档案、酿造配方、语言文件（en_us、zh_cn）、贴图（占位或 `generate_item_textures.py`）、Codex 条目。
- 运行 `generate_essence_resources.py --check`，再 `--write-missing`。
- 运行现有校验脚本（`validate_raw_herb_food_balance.py`、`validate_brewing_recipes.py`、语言键对齐等）。
- 提交后等 CI（build、compile-check、runtime-smoke）通过。
- 在 `CURRENT_BASELINE.md` 记录新草药与自动影响点的决定。

## Implementation status (2026-10-14)

Implemented on the user's choices: Shelf Mushroom A, Poplar leaves A, Poplar sapling A, Red Shrub B (decoration only), Cushion / Straw Bed / Wool / Poplar wood A (no data change).

- Shelf Mushroom: one herb `shelf_mushroom`. Small and large share the item id `minecraft:shelf_mushroom`, so a split into two herbs is not possible at the data level. Only one herb is provided.
- Poplar leaves: `poplar_red_leaves`, `poplar_orange_leaves`, `poplar_yellow_leaves`, each with its own essence and brewing variants. Also added to `minecraft:goat_food`. Poplar leaves join `honey_leaf_soup` automatically through `#minecraft:leaves`. This was not separately confirmed with the user.
- Poplar sapling: `poplar_sapling`, cherry-sapling pattern.
- Balance numbers are derived, not reviewed. Essence textures are recoloured from the cherry template.
- Pending CI checks: `validate_animal_food_tags` (the `goat_food` addition may collide if vanilla 26.3 already lists poplar leaves), `validate_item_textures`, Gradle build, runtime smoke.
