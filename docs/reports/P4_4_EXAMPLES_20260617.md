# P4.4 Example Addon / Datapack — 2026-06-17

Status: implemented in docs/examples; source zip refreshed  
Baseline: Herbcraft `1.1.2` source line, `1.1.3` extension-planning milestone

## Goal

P4.4 provides concrete examples for the extension model established in P4.1-P4.3:

```text
JSON provides content.
Java reads current data and observes events.
Java does not register/replace Herbcraft content in these examples.
```

## Example 2: Java read/event addon

New example:

```text
docs/examples/herbcraft_readonly_event_addon/
```

Key files:

```text
docs/examples/herbcraft_readonly_event_addon/README.md
docs/examples/herbcraft_readonly_event_addon/fabric.mod.json
docs/examples/herbcraft_readonly_event_addon/src/main/java/com/example/herbcraftapi/ExampleHerbcraftApiAddon.java
```

It demonstrates:

```java
HerbcraftDataAPI.nature(itemId)
HerbcraftDataAPI.ingredientEntryId(itemId)
HerbcraftEvents.NUTRITION_APPLIED
HerbcraftEvents.INGREDIENT_DISCOVERED
HerbcraftEvents.FOOD_NATURE_RESOLVED
HerbcraftEvents.EXTERNAL_DATA_RELOADED
```

It intentionally does not call any Java write/registration APIs.

The example `fabric.mod.json` uses:

```json
"herbcraft": ">=1.1.3"
```

because P4 APIs are intended as the `1.1.3` public extension line, even though the current test jars may still carry the `1.1.2` version string until the release bump is chosen.
